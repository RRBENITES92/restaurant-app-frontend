# Restaurant App Frontend

Frontend desarrollado con React + Vite para consumir una API REST en .NET.

## Tecnologías
- React
- Vite
- React Router
- JWT
- CSS
- API REST .NET

## Funcionalidades
- Login con JWT
- Control de roles
- Listado de productos
- Crear productos
- Editar productos
- Desactivar productos
- Paginación
- Protección de rutas

## Cómo ejecutar

npm install
npm run dev
